# Security Review — чеклист для ревьюера

Ревьюер harness проверяет не только соответствие acceptance criteria,
но и безопасность. Этот скилл — чеклист поверх основного ревью.

## Когда активировать

- Любое ревью задачи, затрагивающей: аутентификацию, авторизацию,
  пользовательский ввод, API-эндпоинты, секреты, базу данных,
  платёжные операции, файловые загрузки, внешние API.

## Быстрый чеклист (5 критических пунктов)

### 1. Секреты
- [ ] Нет захардкоженных ключей, токенов, паролей в коде.
- [ ] Все секреты — через env-переменные (`pydantic-settings` / `process.env`).
- [ ] `.env*` в `.gitignore`.

### 2. Валидация ввода
- [ ] Весь пользовательский ввод валидируется (Pydantic / Zod).
- [ ] Нет прямого использования ввода в SQL/shell/eval.
- [ ] Загрузка файлов ограничена (размер, тип, расширение).

### 3. SQL-инъекции
- [ ] Все запросы параметризованы (SQLAlchemy ORM / prepared statements).
- [ ] Нет конкатенации строк в SQL.

### 4. Аутентификация / Авторизация
- [ ] Каждый защищённый эндпоинт проверяет права.
- [ ] JWT в httpOnly cookies (не localStorage).
- [ ] Role-based доступ на уровне сервиса.

### 5. Утечка данных
- [ ] Ошибки не раскрывают внутреннюю структуру (stack trace, SQL).
- [ ] Логи не содержат паролей, токенов, PII.
- [ ] Ответы API не возвращают лишних полей (только DTO).

## Расширенный чеклист

### Python / FastAPI
```
- [ ] `async def` на всех эндпоинтах (нет блокирующих вызовов)
- [ ] `httpx.AsyncClient` вместо `requests`
- [ ] Pydantic v2 с strict-валидацией
- [ ] CORS настроен (не `allow_origins=["*"]` в проде)
- [ ] Rate-limiting на тяжёлых эндпоинтах
- [ ] `datetime.now(tz=UTC)` — нет naive datetimes
```

### TypeScript / Next.js
```
- [ ] Zod-схемы на всех API-входах
- [ ] CSP-заголовки настроены (нет unsafe-inline без причины)
- [ ] XSS-защита: нет `dangerouslySetInnerHTML` без DOMPurify
- [ ] CSRF-защита на state-changing операциях
- [ ] SameSite=Strict на cookies
```

## Вердикт ревьюера

Если найдена хоть одна проблема безопасности:

```
VERDICT: CHANGES
Безопасность:
- [ФАЙЛ:СТРОКА] Захардкоженный API-ключ → вынести в env
- [ФАЙЛ:СТРОКА] SQL-конкатенация → параметризованный запрос
```

Критические проблемы безопасности = CHANGES даже если функционально всё ОК.

## Связь с harness

- Выполняется на шаге REVIEW, параллельно с функциональным ревью.
- Проблемы безопасности — основание для VERDICT: CHANGES.
- Anti-gaming guard защищает зону спеков от воркера; security-review
  защищает прод от воркера.
